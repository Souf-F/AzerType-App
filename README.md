# AzerType

Typing speed trainer built in vanilla JS. First OpenClassrooms project — foundational HTML/CSS/JS with practical keyboard mechanics.

## How it works

```
1. Choose a source (words or random phrases)
2. A prompt appears on screen
3. Type it exactly in the input field
4. Score updates on each correct entry
5. Beat your record before time runs out
```

## Stack

HTML · CSS · JavaScript — no framework, no build step.

## Run

Open  directly in a browser, or serve it locally:

```bash
python3 -m http.server 8080
```

## Structure

```
├── index.html
├── style/
│   └── style.css
└── scripts/
    ├── config.js    # game configuration
    ├── popup.js     # popup UI
    ├── script.js    # core logic
    └── main.js      # entry point
```

## Context

First project built from a precise technical specification at OpenClassrooms — foundation for web development learning.
